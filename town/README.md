# ENGAWA Town — 仕事の前に、おはよう。

**実装候補。未デプロイ。組織への一般提供・Slack置換完了を宣言するものではありません。**

情報の箱ではなく、人が集まる場所から始めるコミュニケーション空間です。組織の家と共有の広場、アバターの気配、近くへのひとこと、横断する個人の机を用意します。3Dを歩かなくても、すべての実務情報は2DのUIから開けます。

## 動かす（ローカル・架空ユーザー専用）

Node.js 22.16以上。追加依存のインストールは不要です。

```sh
node town/server.mjs
# http://127.0.0.1:8789/local/login
# 別ブラウザプロファイルから別の架空ユーザーを選ぶ
npm --prefix town run check
```

ループバックにだけbindし、転送ヘッダーを拒否します。**このデモをトンネル、公開サーバー、社内LAN向け認証の代わりに使わないでください。** ローカルの `.data/town.sqlite` は架空ユーザーの検証データです。新しい日常のログを投入する前に、本物の認証・権限・バックアップを検証してください。

## 実装した機能

3Dの街（WebGL、非対応時は同じ形状のソフトウェア描画）、リアルタイム移動、選べるアバター、集中/離席、手動の挨拶、入れる場所だけを表示する家・共用部、ゲスト表示、近接テキスト、5分の巻き戻し、個人保存と元の場所への明示共有。

組織/場所横断の担当タスク、共有タスクの引受けと完了、プロジェクト名と期限、永続掲示板、ピン留め、返信、権限内の全文検索。持ち寄るメモ、縮小した写真、日ごとの水やりで育つ植物、二人の三目並べ、任意で開始するオリジナルの環境音と小さな楽器。

保存はrevisionと要求IDで保護し、成否不明の保存は自動再送しません。新しい入力を古い応答で消さず、ページを閉じる前に自分の入力だけをJSON退避/復元できます。復元は送信ではありません。JSONは暗号化されていません。

## 意図的な境界

- マイク、通話、画面共有、録音、文字起こし、AI実行、DMは未接続です。権限ヘッダーでマイク等を無効化しています。
- 5分のテキストバッファは、保存に気づけるか検証するための暫定値です。組織の合意済み保持ポリシーではありません。
- 記録できるのは発言時にその場所にいて範囲内で受信対象になった本人だけです。後から近づいても過去の発言は届きません。音声は記録しません。
- 個人保存と共有は別操作です。共有先は元の場所だけ。参加権限を失うと当アプリからその場所の記憶も読めません。既にダウンロード等された複製を取り消せるとは主張しません。
- 在席は勤怠ではありません。位置、接続時間、マイク活動の履歴は保存しません。通信が90秒確認できなくなれば気配は消えます。端末の休止中に「今いる」と保証しません。
- 投稿は人の発言であり、組織の正式な決定や外部実行権限ではありません。

## Cloudflare用の実装

このディレクトリは既存の `engawa-dev` に追加して使います。`worker.ts` は既存 `remote/auth.ts` の実JWT検証、`remote/directory.ts` のmembership + object grantを再利用します。`wrangler.jsonc` は **別Worker `engawa-town`**、別のDurable Objectストアです。既存 `engawa-pilot` は置換しません。townのみのZIPには既存リポジトリの依存コードは含みません。

本番用の静的ファイルは `public/` のみ。架空ログインは含みません。Workersの `run_worker_first` とアプリ内部の署名検証でAPIもアセットも保護します。任意の外部ヘッダーを本人確認として信じません。

検証用コマンド（リポジトリの依存インストール後）：

```sh
npm ci
npm --prefix town run check
npx tsc --project town/tsconfig.json
node --test town/tests/cloud.integration.mjs
```

クラウドへの公開手順と停止条件は `docs/TOWN-ROLLOUT.md`。開発機で通ったテストと未確認の項目は `docs/VERIFICATION-TOWN.md`。ブラウザの実ネットワーク・実IDプロバイダ・複数実機は別の受入試験です。
